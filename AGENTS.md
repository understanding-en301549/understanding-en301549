# Standing orders for coding agents

This file is for coding agents working in this repository. Human contributor process lives in `CONTRIBUTING`; do not duplicate that guide here.

Implement only what the assigned issue asks. Do not add extra pages, tools, or dependencies the issue did not request.

## Project status

This is an unofficial community project. Do not imply standing with ETSI, CEN, or CENELEC. Do not invent a project brand, logo, or visual identity. Keep layout plain.

Language is English only. Do not add analytics, cookies, or tracking.

## Licensing and EN clause text

Code is MIT. Project content is CC BY 4.0.

Quoted EN 301 549 clause text is a separate field and stays hidden until permission to reproduce it exists. Do not paste large EN quotations into other files. Do not invent official or citeable EN clause URLs.

## GitHub workflow

One issue maps to one pull request. Branch from `main`. Never push to `main`. Never merge.

Disclose AI assistance on every pull request.

If the issue is blocked, ambiguous, or CI cannot be made green without expanding scope, stop and comment on the issue instead of working around the brief.
