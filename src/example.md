## Intent

This page exercises the Understanding document template. It shows where each
part of a document goes, so contributors can see the shape of a document
before any clause of EN 301 549 is written up. It explains nothing about the
standard, and nothing on this page should be used as guidance.

## Benefits

Contributors can see what an Understanding document looks like without
waiting for a clause to be written. The template also lets the build show
that the quoted requirement field can be stored in a document without being
published, which is what the project's licensing position requires for now.

## Testing

In a real document, this section explains what to look at when checking a
product against the requirement, and where people commonly go wrong. It is
prose, not a procedure: it does not number steps, it does not say whether a
result passes or fails, and it does not define a test rule. Where a
requirement is easy to confuse with a neighbouring one, this section says so
and points to the other document. Nothing in this template covers any clause
of the standard.
