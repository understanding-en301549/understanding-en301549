# Accessibility statement

This site conforms to EN 301 549 version 4.

If you find an accessibility problem, please
[open an issue on GitHub](https://github.com/understanding-en301549/understanding-en301549/issues/new).
Describe the page, what you were trying to do, and the problem you encountered.

We will review reports and address problems where we can.
