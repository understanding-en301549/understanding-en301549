# Understanding EN 301 549

Unofficial community documents that explain EN 301 549 requirements which are not already covered by W3C Understanding documents for WCAG.

These documents have no standing with ETSI, CEN, or CENELEC. They are not an ETSI, CEN, or CENELEC publication. Editors take part in a personal capacity.

## Purpose

EN 301 549 is the accessibility standard used across Europe for ICT products and services. Where it adopts WCAG, W3C already publishes Understanding documents. This project documents the remaining requirements — the gaps.

The documents explain requirements. They are not test procedures, and they do not define pass or fail criteria.
